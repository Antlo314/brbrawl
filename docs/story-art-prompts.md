# Story mode art prompts (Gemini jobs and Grok Imagine)

Made by `tools/artpipe/story_jobs.py`. Each page: paste the prompt, attach the listed reference images in order (Image 1, Image 2 ...), and save the result into `MM Game/originals/gemini/` under the file name shown (png). Sprite pages are square (1:1, as large as the model allows); level panels are 16:9. Then run `python story_cut.py` in tools/artpipe.
