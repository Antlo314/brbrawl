# Tracks for the adaptive music (run: python tools/batch_tracks.py). One track per line:
#
#   name | BPM | key | style | mood | extras (optional)
#
# name    a-z, 0-9 and _ (it names the files). The same name always makes the same track; to try another take, change the name or add seed=.
# BPM     a whole number. Tracks that should switch into each other in a mode share BPM and key.
# key     like C minor, F# minor, Bb major.
# style   genre and lead sounds. The drums, 808, piano, bells and synth the game's layers are cut from get added for you.
# mood    a few words.
# extras  seed=123  seconds=120  bars=16  caption=<a whole caption of your own, used instead of style + mood: keep it last>
#
# A track that's already made is skipped (delete its files to make it again). A # after a space starts a comment.
